## Install the binary

1. Download `texturescript-OS-ARCH` for your system from the
   [releases](https://github.com/witoldwozniak/texturescript/releases).
2. Make it executable and put it on your `PATH`:

   ```sh
   chmod +x texturescript-linux-x64
   mv texturescript-linux-x64 ~/.local/bin/texturescript
   ```

3. Check it runs:

   ```sh
   texturescript --version
   ```

The binary includes the 3D viewer and the authoring skill and needs nothing else. Only the Linux
x64 build has been tested so far.

## Install from source

You need [Bun](https://bun.sh).

```sh
git clone https://github.com/witoldwozniak/texturescript
cd texturescript
bun install
bun link           # puts `texturescript` on your PATH
```

`bun run build` compiles the binary into `dist/`.

## Enable screenshots

`shoot`, and file-name labels on `sheet`, drive a headless Chromium. TextureScript looks for one
in this order:

1. the executable named by `TEXTURESCRIPT_CHROMIUM`;
2. Playwright's own Chromium;
3. an installed Google Chrome.

If you have none of them, download Playwright's:

```sh
npx playwright-core install chromium
```

`view` uses your own browser and needs none of this.

## Show vanilla blocks

Scenes can plant vanilla blocks beside yours. TextureScript reads them at run time from the
newest client jar your launcher has downloaded, from the official launcher or Prism Launcher
(including the Flatpak). Check which jar it found:

```sh
texturescript jar
```

If it finds none, or the wrong one, pass `--jar PATH` to `view`, `shoot`, `mcp` or `fetch`. To
work without a jar, pass `--no-jar`: only your own blocks are drawn and the vanilla ones are
listed as missing. See [Environment](/reference/environment) for the folders searched.
