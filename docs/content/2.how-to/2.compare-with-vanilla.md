A crop's density and read can only be judged on the block model, next to vanilla. This guide
assumes you have a `.stages` file for your crop and Minecraft installed (see
[Install TextureScript](/how-to/install#show-vanilla-blocks)).

## Write the scene

Create a TOML file next to your `.stages` file:

```toml [tomato.toml]
camera = { yaw = 30, pitch = 22, distance = 7 }
floor = "minecraft:grass_block"
ground = "minecraft:farmland[moisture=7]"

[[plot]]
label = "tomato"
stages = "tomato.stages"
ages = [0, 3, 7]
at = [0, 0]

[[plot]]
label = "wheat (vanilla)"
block = "minecraft:wheat[age=7]"
at = [4, 0]
```

- Each age takes the next block along +x, so `ages = [0, 3, 7]` at `[0, 0]` fills x 0 to 2.
- Leave one empty block between plots, along x and z. Plots that touch merge into one bed and
  their labels overlap.
- Use `model = "cross"` for flowers and saplings, which sit on two diagonal planes.
- `block` takes any block state your jar has, like `minecraft:sunflower[half=lower]`.

Every key is described in [Scene files](/reference/scene-files).

## Look at it live

```sh
texturescript view tomato.toml
```

The view updates whenever you save the scene, a grid, a palette or a map. Drag to orbit, scroll
to zoom, `l` toggles labels.

## Screenshot it

When you cannot see a browser, or want a picture to share, shoot the same scene. One angle hides
overlaps, so take two or three:

```sh
texturescript shoot tomato.toml shot.png --cam 30,22,7 --cam 120,10,5 --cam 0,60,6
```

Those frame the whole scene. To judge one plant, move in and enlarge the shots:

```sh
texturescript shoot tomato.toml close.png --cam 30,22,4 --size 900x600
```

## Compare two drafts

Give a plot several `stages` as named variants:

```toml
[[plot]]
label = "tomato"
stages = { first = "tomato-a.stages", second = "tomato-b.stages" }
at = [0, 0]
```

In `view`, keys 1 to 9 switch between variants and `v` cycles through them. `shoot` puts each
variant in its own row of the sheet; `--variant NAME` limits it to some of them.

## Compare items

Items are flat, so compare them on a contact sheet instead, at three times their size:

```sh
texturescript sheet items.png out/corn_item.png vanilla-items/ --scale 3
```
