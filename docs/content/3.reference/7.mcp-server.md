`texturescript mcp` is an MCP server on stdio. Relative paths are relative to the directory the
server starts in. `--jar PATH` and `--no-jar` choose the vanilla blocks for `shoot`.

## Tools

Each tool returns text, structured data and, where there is a picture, the picture as an image.
A broken input comes back as an error result starting with `REFUSED`.

### render

Renders a grid like `grid` and returns the ×16 preview.

| parameter | type | |
|---|---|---|
| `spec` | path | character grid (`.grid`) |
| `out` | path | PNG to write; `OUT_x16.png` and `OUT.txt` are written beside it |

### lint

Lints a PNG like `lint`. Read-only.

| parameter | type | |
|---|---|---|
| `texture` | path | 16×16 PNG to check |
| `kind` | `"block"` or `"item"` | optional; default `block` |
| `lower` | path | optional; marks `texture` as the upper half and checks the seam |
| `palette` | path | optional; family palette every colour must come from |

### shoot

Screenshots a scene like `shoot` and returns the sheet. Grids, palettes and `.stages` files are
read fresh on every call.

| parameter | type | |
|---|---|---|
| `scene` | path | scene file (`.toml`) |
| `out` | path | PNG to write: one shot, or a labelled sheet |
| `cameras` | array of `{ yaw, pitch, distance }` | optional; default: the scene's camera |
| `variants` | array of strings | optional; default: all |
| `width`, `height` | integers | optional; size of each shot, default 960 × 540 |
| `labels` | boolean | optional; draw plot labels, default true |
