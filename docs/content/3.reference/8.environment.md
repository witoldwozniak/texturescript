## Minecraft client jar

Without `--jar`, TextureScript uses the newest client jar in these launcher folders:

| system | folders |
|---|---|
| Linux | `~/.minecraft`, `$XDG_DATA_HOME/PrismLauncher` (default `~/.local/share/PrismLauncher`), `~/.var/app/org.prismlauncher.PrismLauncher/data/PrismLauncher` |
| macOS | `~/Library/Application Support/minecraft`, `~/Library/Application Support/PrismLauncher` |
| Windows | `%APPDATA%\.minecraft`, `%APPDATA%\PrismLauncher` |

`texturescript jar` prints the one in use.

## Chromium

`shoot`, the MCP `shoot` tool and file-name labels on `sheet` need a headless Chromium. In order:

| source | |
|---|---|
| `TEXTURESCRIPT_CHROMIUM` | path to a Chromium or Chrome executable |
| Playwright | the Chromium installed by `npx playwright-core install chromium` |
| Google Chrome | an installed Chrome |

`view` opens your default browser and needs none of these.

## Cache

The pre-commit check caches fingerprints of the jar's files, only hashes, under `$XDG_CACHE_HOME/texturescript`
(default `~/.cache/texturescript`).
