A scene is a TOML file that says what to plant where and how to look at it. Relative paths are
relative to the scene file.

```toml [corn.toml]
camera = { yaw = 30, pitch = 22, distance = 7 }
floor = "minecraft:grass_block"
ground = "minecraft:farmland[moisture=7]"

[[plot]]
label = "corn"
stages = "corn.stages"
ages = [0, 3, 7]
model = "crop"
at = [0, 0]

[[plot]]
label = "wheat (vanilla)"
block = "minecraft:wheat[age=7]"
ground = "minecraft:grass_block"
at = [4, 0]
```

## Top level

| key | type | meaning |
|---|---|---|
| `camera` | `{ yaw, pitch, distance }` | starting view: degrees around, degrees above the horizon, blocks from the centre |
| `floor` | block state | under the whole area |
| `ground` | block state | under each planted cell |
| `plot` | array of tables | the things to plant |

## Plots

Each plot has exactly one of `stages` and `block`.

| key | type | meaning |
|---|---|---|
| `label` | string | shown above the plot; default `plot N` |
| `stages` | path, or table of paths | a `.stages` file, a folder written by `stages`, or named variants `{ a = "a.stages", b = "out" }` |
| `block` | block state | any block from your client jar, like `minecraft:sunflower[half=lower]` |
| `ages` | array of integers | stages to plant, one per block along +x; default: all |
| `model` | `"crop"` or `"cross"` | four planes in a hash (crops, the default) or two diagonals (flowers, saplings) |
| `at` | `[x, z]` | position of the first block; default `[0, 2 × index]` |
| `ground` | block state | this plot's ground instead of the scene's |

## Behaviour

- A `.stages` plot is compiled in memory, so `view` follows edits to its grids, palette and maps
  without running `stages`. A folder plot shows the files as they are on disk, including
  hand-edited stages.
- Variants are alternatives to compare. `view` switches between them; `shoot` puts each in its
  own row. A scene without named variants has one, `default`.
- Blocks that cannot be found are listed in the view and on the command line, and left out.
- Leave one empty block between plots, along x and z: plots that touch merge into one bed and
  their labels overlap.
